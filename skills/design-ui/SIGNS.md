# Signs of generic UI

Each sign below shows up when an agent designs without choosing. Find the signs on the rendered screen, then apply the fix. A sign that the brief, the design system or the chosen world calls for on purpose is not a problem: ruled lines on a ledger, or a stamped uppercase label on a stamp.

Contents: page structure, clutter, colour and effects, type, copy, icons, spacing.

## Page structure

| Sign | Fix |
| :- | :- |
| A small uppercase label (an eyebrow) above every heading | Delete it. The heading carries its own weight. |
| Hero with a headline, a paragraph, two buttons and an image on the right | Build the hero from what this product shows best. One primary action; the second button only if users really need it. |
| A row of identical cards, each an icon, a heading and two lines of text | Write it as a list or prose with good spacing, or give each item the space and form its content needs. |
| A big number, a small label and a row of supporting stats | Show the number in context, or leave it out if it isn't real. |
| Section numbers (01, 02, 03) on things that aren't a sequence | Remove them. Keep numbers only for real steps. |
| A logo wall, testimonials or metrics with no real source | Remove them, or leave a clearly marked placeholder. |
| A modal for a task that doesn't need to block the page | Do it in place, in a panel or on its own page. |

## Clutter

| Sign | Fix |
| :- | :- |
| Every group wrapped in a card | Group with space and alignment. Keep cards for distinct objects. |
| A card inside a card | Remove the inner box; use space or a subtle background step. |
| A divider between every row or section | Remove them and add space between groups. |
| Helper text under every field or heading | Keep it only where the label can't say it. |
| Several buttons of equal weight | One primary action; the rest become secondary or move into a menu. |
| Everything shown at once | Show what most users need; put detail behind a click. |
| Nested sidebars, or a sidebar and a top menu that repeat each other | One level of navigation that's always visible. |
| Badges and chips on everything | Keep them for status that changes; drop decorative ones. |
| Sparklines or progress rings on every stat | Keep one where the trend matters; plain numbers elsewhere. |

## Colour and effects

| Sign | Fix |
| :- | :- |
| Purple-to-blue gradients, glows or blurred colour blobs | Use a solid neutral ground and one accent. If a gradient is the signature, use one, in one place. |
| Gradient text | Use weight or size for emphasis. |
| A dot grid or line grid behind content for no reason | Use a plain surface; texture only if the subject's world has one. |
| Glassmorphism and backdrop blur as decoration | Use a solid surface; blur only where content really passes underneath. |
| The same soft shadow and large radius on everything | Pick border or shadow per level, and scale radius by element size. |
| A border and a wide shadow on the same card | Keep one of them. |
| A coloured bar down one side of a rounded box | Use a tint, an icon or a full border. |
| Many slightly different tints of the accent | One accent colour, plus one soft version for selected backgrounds. |
| Status shown only as a coloured dot or text | Add a word or an icon. |

## Type

| Sign | Fix |
| :- | :- |
| The default font every agent picks, chosen because it's safe | Choose a face from the product's world and give it a role. |
| One accented or italic word in a headline | Set the whole headline in one style. |
| Tracked uppercase labels everywhere | Sentence case at a smaller size or muted colour. |
| Very heavy headings (800 or 900) on everything | Use 500 to 700, with size doing the rest. |
| Monospace for labels and metadata to look technical | Use the body face; keep mono for code and data. |
| Body text running the full width of a wide screen | Cap the line at 65 to 75 characters. |
| Centred paragraphs or centred sidebar titles | Left-align them. |

## Copy

| Sign | Fix |
| :- | :- |
| "Welcome back! 👋" or "Hello there" as a headline | Show what the user came for. |
| Exclamation marks, "Oops!", "Awesome!" | Plain, calm statements. |
| "New ✨" badges and sparkle icons on AI features | Name what the feature does. |
| "Submit", "OK", "Click here" | A verb and an object: "Send invite", "Save changes". |
| "+12%!!" with no context | "+12% vs last month". |
| Lorem ipsum or "Item 1, Item 2" | Realistic content for this product. |
| A paragraph explaining what the screen does | Cut it; make the screen obvious instead. |

## Icons

| Sign | Fix |
| :- | :- |
| Emoji used as icons | Use one icon set, in one stroke weight. |
| Icons from mixed sets, or mixed filled and outline styles | Pick one set and one style. |
| An icon in a coloured circle next to every heading | Drop the circle, or the icon. |
| An icon with a double ring or doubled border | One ring, or none. |
| A small icon button with no hit area or uneven padding | Give it a square hit area of at least 32px (44px on touch) and centre the icon. |

## Spacing

| Sign | Fix |
| :- | :- |
| Arbitrary values (13px, 22px, 37px) | Snap to the 4px scale. |
| Equal space inside and between groups, so nothing groups | Tighten inside groups and widen between them. |
| Heavy padding at the screen edges on mobile | About 16px at the edges; spend space between groups instead. |
| Oversized inputs and buttons on mobile | Use the compact control size. |
| Deep indents on nested items | One small indent step, or none. |
| Empty bands or a gap under the last section | Remove the empty space; keep the footer at the bottom of the viewport. |
| Text touching an edge, or overlapping another element | Fix the layout, not the content. Render again to confirm. |
