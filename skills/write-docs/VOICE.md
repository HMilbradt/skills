# Voice

How the docs should sound, who they're for, and the words and patterns to leave out.

## Who reads these docs

Three readers, often on the same page:

| Reader | What they need |
| :- | :- |
| AI agents | Exact strings, explicit conditions, one name per thing, and the expected result of each step. They follow instructions literally. |
| Software engineers | The command, the edge cases, and where to look next. They're busy and they skim. |
| Non-technical people | What this means for them and what to do, without jargon. |

Plain, exact writing serves all three. Experts prefer plain language too, especially on complex subjects, so writing plainly doesn't mean dumbing down.

## The voice

Write like a senior engineer explaining something to a smart colleague who is short on time.

- Lead with the answer or the outcome. Context comes after, if it's needed at all.
- Short sentences, one idea each. Everyday words. Technical words only where they're more precise, defined once.
- Active voice, "you", present tense. Contractions are fine.
- Confident about what you know. Plain about what you don't: "not tested", "I don't know which".
- No hype, no padding, no sign-off.
- Name the details a reader needs to act on, and nothing else.

Stripe's docs are the model: a one-line summary up top, a working example, the result you should see, and errors that say what happened and what to do.

## Words to avoid

| Avoid | Use instead |
| :- | :- |
| delve, dive into, deep dive | look at, explain, or cut |
| leverage, utilise, utilize | use |
| facilitate, enable, empower | let, help, or name the action |
| robust, seamless, powerful, cutting-edge, blazing fast | say what it does, or cut |
| comprehensive, holistic | complete, or cut |
| crucial, pivotal, key (as an adjective), vital | important, or show why it matters |
| streamline | simplify, speed up, or name the change |
| showcase, boasts, features (meaning "has") | shows, has |
| serves as, stands as, functions as, represents | is |
| a testament to, underscores, highlights the importance of | state the fact |
| landscape, ecosystem, tapestry, realm | name the actual thing |
| ensure (as filler) | make sure, check, or cut |
| in order to | to |
| prior to, subsequent to | before, after |
| commence, initiate | start |
| smoking gun | the cause, the evidence |
| under the hood | inside, or cut |
| simply, just, easily, obviously | cut |

## Phrases to avoid

| Avoid | Use instead |
| :- | :- |
| It's worth noting that, It's important to note that, Note that | state the fact |
| In summary, In conclusion, Overall, To sum up | end without a closer |
| Let's dive in, Let's take a look, Great question | start with the content |
| I hope this helps, Happy coding, Let me know if | end without a sign-off |
| Not only X but also Y; It's not X, it's Y; No X, no Y, just Z | state X and Y plainly |
| X, ensuring Y (or highlighting, fostering, enabling Y) | a separate sentence that says how X causes Y |
| may potentially, could possibly | may, could |
| Experts say, Many users find | name who, or cut |
| currently, at the moment, as of now, recently, new, latest | cut, or give the version that matters |
| a variety of, a number of, various | name them, or say "several" |
| going forward, moving forward | from now on, or cut |

## Patterns to avoid

| Avoid | Use instead |
| :- | :- |
| Em dashes and double hyphens in prose | a period, comma, colon or parentheses |
| Bullets that start with a bold label and a colon | a sentence, a table or a heading |
| Bullet lists for reasoning | a short paragraph |
| Three adjectives or phrases in a row for rhythm | the one that is true |
| Bold scattered through prose | bold only for UI labels the reader must find |
| Emoji in headings or lists | nothing |
| Title Case Headings | sentence case headings |
| A closing paragraph that repeats the section | end when the content ends |
| Several "Note", "Tip" and "Important" callouts | one callout, only for something that will hurt if missed |
| Swapping synonyms for the same thing (server, host, box) | one term, used every time |
